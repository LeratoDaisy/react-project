# User Directory

## Overview

This project is a React application that demonstrates data fetching, controlled components, and forms.

## Features

* Fetches users from JSONPlaceholder API
* Displays user name, email, and company
* Search users by name
* Shows "No users found" when there are no matches
* Add a new user without refreshing the page (Bonus)

## Technologies Used

* React
* JavaScript
* CSS
* JSONPlaceholder API

## Installation

```bash
npm install
npm start
```

## Deployment

Deployed using Vercel.
